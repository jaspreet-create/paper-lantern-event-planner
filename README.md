# Bunting – Event Planning Assistant

Bunting is a responsive event-planning web application that helps users organize weddings, birthdays, and community events in one place.

## Features

* Event customization
* Budget planning and allocation
* Event timelines and countdowns
* Vendor checklists and expense tracking
* Creative event ideas
* Interactive planning assistant
* Responsive user interface
* Local data storage

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Bunting-Event-Planner.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.
